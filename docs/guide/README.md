# 使用手冊

給要使用 Loop Engineering 的人：Project Lead、Engineer、驗收人。手冊有兩份：[使用指南](user-guide.md)講流程，[參考手冊](reference.md)講每一步的細節。手冊只說怎麼做；規則本身與設計理由在[內部設計文件](../README.md#你要讀哪裡)。

| 想做什麼 | 讀哪裡 |
| --- | --- |
| 第一次了解整個流程 | [使用指南](user-guide.md)：先看「大圈包小圈」那張圖 |
| 照著做某個活動 | 使用指南的[外圈](user-guide.md#外圈project)與[內圈](user-guide.md#內圈一個-feature)：每個活動一張卡 |
| 跟著範例走一遍 | 參考手冊的[演練路線](reference.md#演練路線用-cross-node-file-transfer-跟走一遍) |
| 查每一步的細節：需求怎麼問、spec 怎麼寫、交接、gates 的證據、常見問題 | **[參考手冊](reference.md)**；每張卡片最後的「細節」直接連到對應小節 |
